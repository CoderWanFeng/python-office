## 简介

python-office 的图片处理模块（`office.image`）基于 poimage 库，提供 9 个功能，覆盖图片压缩、水印添加/去除、风格转换、词云生成、二维码解析等场景。

## 功能列表

| 功能 | 函数名 | 说明 |
|------|--------|------|
| 图片压缩 | `compress_image` | 压缩图片，减小文件大小 |
| 图片加水印 | `add_watermark` | 给图片添加文本水印 |
| 图片去水印 | `del_watermark` | 去除图片水印 |
| 生成词云 | `txt2wordcloud` | 根据文本生成词云图 |
| 铅笔画风格 | `pencil4img` | 将图片转换为铅笔画风格 |
| 卡通风格 | `img2Cartoon` | 将图片转换为卡通风格 |
| 下载图片 | `down4img` | 从 URL 下载图片 |
| 解析二维码 | `decode_qrcode` | 解析二维码图片内容 |
| 图片转 GIF | `image2gif` | 将图片转换为 GIF 格式 |

## 图片压缩

### compress_image
压缩图片文件大小，同时尽量保持视觉质量。

```python
import office

office.image.compress_image(
    input_file='big.jpg',
    output_file='small.jpg',
    quality=30
)
```

**参数说明：**
- `input_file`: 输入图片路径
- `output_file`: 压缩后图片保存路径
- `quality`: 压缩质量（0-95），数值越高越好但文件越大

## 水印处理

### add_watermark — 添加水印
给图片添加文本水印，支持自定义颜色、大小、透明度、角度等。

```python
office.image.add_watermark(
    file='photo.jpg',
    mark='@python-office',
    output_path='./',
    color="#eaeaea",
    size=30,
    opacity=0.35,
    space=200,
    angle=30
)
```

### del_watermark — 去除水印
从图片中去除水印。

```python
office.image.del_watermark(
    input_image='watermarked.jpg',
    output_image='clean.jpg'
)
```

## 风格转换

### txt2wordcloud — 生成词云
根据文本文件生成词云图像。

```python
office.image.txt2wordcloud(
    filename='article.txt',
    color='white',
    result_file='wordcloud.png'
)
```

### pencil4img — 铅笔画风格
将图片转换为铅笔画风格。

```python
office.image.pencil4img(
    input_img='photo.jpg',
    output_path='./',
    output_name='pencil.jpg'
)
```

### img2Cartoon — 卡通风格
将图片转换为卡通风格，基于百度 API。

```python
office.image.img2Cartoon(
    path='photo.jpg',
    client_api='your_api_key',
    client_secret='your_secret'
)
```

## 其他功能

### down4img — 下载图片
从 URL 下载图片并保存到指定路径。

```python
office.image.down4img(
    url='https://example.com/image.jpg',
    output_path='./',
    output_name='downloaded',
    type='jpg'
)
```

### decode_qrcode — 解析二维码
解析二维码图片内容。

```python
office.image.decode_qrcode(qrcode_path='qrcode.png')
```

### image2gif — 图片转 GIF
将图片转换为 GIF 格式。

```python
office.image.image2gif()
```
