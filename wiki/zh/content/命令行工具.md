## 简介

`python-office` 从 **1.1.0** 版本起提供命令行入口 `po`。安装后无需编写 Python 代码，即可在终端、脚本、CI 流水线或 AI Agent 中直接调用办公自动化能力。

```bash
po pdf merge2pdf a.pdf b.pdf --output-file merged.pdf
po excel excel2pdf report.xlsx report.pdf
po tools url2ip www.python-office.com
```

## 安装与验证

```bash
pip install python-office
```

验证安装：

```bash
po --version
# po 1.1.0 (python-office)

po --help
```

`po` 命令由 `setup.cfg` 的 `console_scripts` 入口点注册：

```ini
[options.entry_points]
console_scripts =
    po = office.cli.main:main
```

`python -m office` 是等价入口，由 `office/__main__.py` 提供，适合无法直接调用 `po` 的环境。

## 命令结构

命令采用「模块 + 子命令」两级结构：

```text
po [--json] <module> <command> [positional args] [--options]
```

| 层级 | 说明 | 示例 |
|---|---|---|
| 模块 | 对应 `office.api` 下的 API 模块 | `pdf`、`excel`、`file`、`image`、`tools`、`markdown`、`finance` |
| 子命令 | 对应 API 模块中的具体函数 | `merge2pdf`、`excel2pdf`、`url2ip` |

每个层级都提供独立的帮助信息：

```bash
po --help                  # 列出全部模块
po pdf --help              # 列出 pdf 模块的全部子命令
po pdf merge2pdf --help    # 查看单个子命令的参数
```

## 参数写法

### 位置参数与选项

注册表中 `positional: True` 的参数成为位置参数，其余以 `--kebab-case` 长选项形式出现。Python 的下划线命名在命令行中转为中划线：

```bash
po file replace4filename ./目录 "旧文本" --file-rename true --suffix .txt
```

对应的 API 函数签名是 `replace4filename(path, del_content, replace_content, dir_rename, file_rename, suffix)`。

### 布尔参数

`type: "bool"` 的参数接受 `true/false/1/0/yes/no/on/off`，并显示为 `BOOL`：

```bash
po file replace4filename ./目录 "旧文本" --dir-rename false
```

### 必填参数

`required: True` 的参数缺失时 argparse 直接报错并给出退出码 2：

```bash
po pdf encrypt4pdf in.pdf
# po: error: the following arguments are required: --password
```

## JSON 机器可读输出

`--json` 开关让 stdout 只输出一行 JSON，是脚本、CI 与 AI Agent 调用的推荐方式。

成功：

```json
{"ok": true, "result": "1.2.3.4"}
```

失败（退出码 1）：

```json
{"ok": false, "error": "FileNotFoundError: [Errno 2] No such file or directory: 'a.pdf'"}
```

### stdout 纯净性

库内部函数会通过 `print` 输出进度条。分发层将库内部输出重定向至 stderr，保证 stdout 只有一行 JSON：

```text
stdout:  {"ok": true, "result": null}
stderr:  rows: 100%|██████████| 5/5 ...
```

这一点有专门的测试用例覆盖（`test_dispatch_json_mode_keeps_stdout_clean_when_library_prints`）。

### 退出码

| 退出码 | 含义 |
|---|---|
| `0` | 执行成功 |
| `1` | 运行期错误（文件不存在、依赖缺失等） |
| `2` | 用法错误（未知模块、未知子命令、缺少必填参数） |

## 平台守卫

分发层在导入目标模块**之前**检查平台限制。Windows 专属模块（`poppt`、`poword`、`PyOfficeRobot`、`search4file`）在 macOS / Linux 上会被拦截：

```text
po: error: module 'xxx' is only available on: win32 (current: darwin)
```

当前第一波注册的 7 个模块均为跨平台模块，`platforms` 字段全部为 `None`。尚未纳入本波的模块（`word` / `ppt` / `video` / `web` / `wechat`）当前直接不存在：

```bash
po ppt ppt2pdf
# po: error: argument <module>: invalid choice: 'ppt' (choose from excel, file, finance, image, markdown, pdf, tools)
```

第二波补齐后，Windows 专属部分将走守卫逻辑——**先守卫后导入，跨平台调用不触发任何 import**。

## Python 与命令行等价关系

CLI 只是 `office.api` 的一层薄封装，不修改任何现有模块，原有 Python 用法完全不变：

| 命令行 | Python |
|---|---|
| `po pdf merge2pdf a.pdf b.pdf` | `office.pdf.merge2pdf([...])` |
| `po excel excel2pdf in.xlsx out.pdf` | `office.excel.excel2pdf(...)` |
| `po tools url2ip example.com` | `office.tools.url2ip(...)` |

也可以直接从 Skills 系统导入：

```python
from skills.pdf import pdf2docx
from skills.excel import excel_diff
```

## 实现架构

### 声明式注册表

`office/cli/commands.py` 是一个纯数据的注册表，自包含全部参数信息。构建 argparse 解析器时**不 import 任何 `office.api` 模块**，只有真正分发调用时才通过 `importlib.import_module` 延迟导入。

因此 `po --help` 的构建过程零依赖——只装了 `popdf` 的用户也能秒开帮助，不会因缺少 `povideo` 等重依赖而报错。

注册表条目结构：

```python
"pdf2docx": {
    "help": "Convert PDF to docx",
    "params": [
        {"name": "input_file", "positional": True, "metavar": "PDF",
         "help": "input PDF file"},
        {"name": "output_file", "help": "output docx file"},
    ],
},
```

新增命令只需追加数据条目，无需修改分发与解析逻辑。

### 参数签名过滤

分发时用 `inspect.signature` 过滤出目标函数真正接受的参数，注册表多写的字段不会传入 API 函数，避免 `TypeError`。

### 平台守卫与延迟导入顺序

```text
解析参数 → 平台守卫 → 延迟导入目标模块 → 签名过滤 → 调用
```

### 懒加载的配合

`office/__init__.py` 在 Python ≥ 3.7 时按 PEP 562 懒加载 14 个 API 模块，`import office` 不再拖入整套 `po*` 依赖树。这让 CLI 启动更快，也让「只装核心子库」的轻量安装成为可能。

## 常见问题

### Q1：`po` 命令找不到

确认安装成功：

```bash
pip show python-office
```

若安装正常但命令不在 PATH 中，可用等价入口：

```bash
python -m office --help
```

### Q2：`po --help` 报缺少依赖

`po --help` 本身零依赖，出现缺依赖错误通常说明 Python 环境异常。可用 `--json` 模式确认报错内容：

```bash
po --json pdf merge2pdf /tmp/nonexistent.pdf
```

### Q3：中文路径或参数报错

终端下建议给含空格或中文的参数加引号：

```bash
po pdf merge2pdf "./我的 文件/a.pdf" "./我的 文件/b.pdf"
```

### Q4：如何只安装 CLI 所需的核心依赖

```bash
pip install python-office popdf poexcel poimage pofile wftools pomarkdown
```

`po` 的 7 个模块只依赖这些子库。

### Q5：`--json` 输出的 `result` 是 `null`

多数命令的 API 函数没有返回值，成功时 `result` 即为 `null`，需检查产物文件是否已生成。
