## 简介

`python-office` 是中文世界最受欢迎的 Python 办公自动化库，提供 73 个开箱即用的 Skill，覆盖 PDF、Word、Excel、PPT、图片、视频、微信、邮件等场景。本教程将引导您从零开始，快速掌握核心功能的使用方法。

所有功能均通过统一的 `office` 接口调用，无需深入了解底层实现细节，即可在 5 分钟内完成第一个办公自动化任务。

## 安装与验证

首先，使用 pip 安装 `python-office` 库：

```bash
pip install -i https://mirrors.aliyun.com/pypi/simple/ python-office -U
```

安装完成后，验证安装是否成功：

## 核心功能快速上手

### PDF转Word

将 PDF 文件转换为 Word 文档是常见需求。使用 `office.pdf.pdf2docx()` 函数即可轻松实现。

```python
import office

office.pdf.pdf2docx(
    input_file='report.pdf',
    output_file='report.docx'
)
```

**关键参数说明：**
- `input_file`: 输入 PDF 文件的路径
- `output_file`: 输出 Word 文件的路径，必须包含 `.docx` 后缀

该功能底层调用 popdf 库，基于 pdf2docx 实现高质量转换。

- [office/api/pdf.py](file://office/api/pdf.py#L48-L87)

### 图片压缩

压缩图片文件大小，同时尽量保持视觉质量。

```python
import office

office.image.compress_image(
    input_file='big.jpg',
    output_file='small.jpg',
    quality=30
)
```

**关键参数说明：**
- `input_file`: 输入图片路径
- `output_file`: 压缩后图片保存路径
- `quality`: 压缩质量，取值 0-95，数值越高质量越好但文件越大

**Section sources**
- [office/api/image.py](file://office/api/image.py#L21-L35)

### 图片加水印

给图片添加自定义文本水印。

```python
import office

office.image.add_watermark(
    file='photo.jpg',
    mark='@python-office'
)
```

**关键参数说明：**
- `file`: 图片文件路径
- `mark`: 水印内容
- `output_path`: 输出路径（默认当前目录）
- `color`: 水印颜色（默认 `#eaeaea`）
- `opacity`: 不透明度（默认 0.35）

### 生成词云

根据文本文件生成词云图像。

```python
import office

office.image.txt2wordcloud(
    filename='article.txt',
    result_file='wordcloud.png'
)
```

**关键参数说明：**
- `filename`: 文本文件路径
- `color`: 词云背景色（默认 `white`）
- `result_file`: 输出词云图片路径

### Excel模拟数据

自动创建 Excel 文件并填充模拟数据。

```python
import office

office.excel.fake2excel(
    columns=['name', 'phone'],
    rows=1000,
    path='test.xlsx'
)
```

**关键参数说明：**
- `columns`: 列名列表，支持 name、phone、email 等多种类型
- `rows`: 生成的行数
- `path`: 输出 Excel 文件路径
- `language`: 数据语言（默认 `zh_CN` 中文，可选 `english`）

### 批量重命名文件

批量修改文件/文件夹名称。

```python
import office

office.file.replace4filename(
    path='./test_dir',
    del_content='old',
    replace_content='new'
)
```

**关键参数说明：**
- `path`: 需要修改文件名称的根目录
- `del_content`: 需要替换的内容
- `replace_content`: 替换后的内容（不填则实现删除效果）

## Skills 系统快速上手

python-office 内置 73 个 Skill，每个 Skill 可独立导入：

```python
# 方式 1：直接导入 Skill
from skills.pdf import pdf2docx
pdf2docx(input_file='report.pdf', output_file='report.docx')

# 方式 2：导入分类模块
from skills.image import compress_image
compress_image(input_file='big.jpg', output_file='small.jpg', quality=30)

# 方式 3：传统 office 风格（仍然可用）
import office
office.image.compress_image(input_file='big.jpg', output_file='small.jpg', quality=30)
```

每个 Skill 目录下都有 `SKILL.md` 文件，详细说明参数、返回值和使用示例，可被 AI 工具自动识别。

## 常见注意事项

1. **文件路径处理**：建议使用绝对路径或基于 `os.path` 的相对路径构造，避免因工作目录不同导致文件找不到。
2. **跨平台兼容性**：poword（Word处理）、poppt（PPT处理）、PyOfficeRobot（微信机器人）仅支持 Windows，macOS/Linux 首次运行会看到兼容性提示。
3. **参数弃用**：部分函数支持新旧参数名共存，使用旧参数会触发 DeprecationWarning，建议迁移到新参数名。
4. **子库独立安装**：如果只需特定功能，可以单独安装对应子库（如 `pip install popdf`），减少依赖体积。
5. **Windows 专用功能延迟加载**：wechat、word 等模块在非 Windows 环境下不会导致 `import office` 失败，但调用对应功能时会报错。
